# DUC 7: Global Particulate Organic Carbon (POC) flux from Particle Size Distribution (PSD) data

Code to predict and visualise POC flux from PSD data coming from Underwater Vision Profiler (UVP) inside a R Shiny app.

This work is part of the DTO-BioFlow project (GA No. 101112823), which received funding from the European Union’s Horizon Programme call HORIZON-MISS-2022-OCEAN-01, and especially part of the Demonstrator Use Case (DUC) 7 related to ecosystem services (more information at https://dto-bioflow.eu/use-cases/duc7-ecosystem-services-including-carbon-sequestration).
